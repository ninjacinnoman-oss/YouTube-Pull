Ninjacinnoman Dashboard

Privacy policy

Last updated November 13, 2026.

Who uses this app

Ninjacinnoman Dashboard is a personal tool used only by the owner of the Ninjacinnoman YouTube channel to view that channel's own statistics. It is not offered to anyone else.

Information it accesses

With the owner's permission, through Google's sign-in, the app reads the following with read-only access:

  • YouTube Analytics reports for the owner's channel: views, engaged views, watch time, subscribers gained and lost, per day and per video;
  • YouTube Analytics monetary reports: estimated revenue, per day and per video;
  • the owner's YouTube account information: the channel's title, public subscriber count and list of videos;
  • public YouTube search results about Call of Duty and gaming retrospectives.

It does not read email, contacts, comments, messages or any other Google data, and it never changes anything on YouTube.

How it is used and stored

  • The information is saved as files on the owner's own computer and shown in a private dashboard that only the owner can open.
  • The sign-in token is stored only on the owner's computer.
  • Nothing is sold, shared with third parties or used for advertising.

Ninjacinnoman Dashboard's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Removing it stops all further reads. The files already saved can be deleted from the owner's computer.

Contact

Questions can be sent through the Ninjacinnoman channel.
